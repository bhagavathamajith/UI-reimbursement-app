# University Receipt Reimbursement App

A minimal full-stack web application that allows university employees to submit receipts for reimbursement. Built using Angular 17 (standalone components), Node.js with Express, and MongoDB.

---

## Tech Stack

| Layer        | Tech                      |
|--------------|---------------------------|
| Frontend     | Angular 17 (Standalone API) |
| Backend      | Node.js + Express         |
| Database     | MongoDB (local or Atlas)  |
| File Uploads | Multer                    |

---

## How to Run This App

### Frontend (Angular)
```
cd frontend
npm install
ng serve
```
### Backend (Express)
```
cd backend
mkdir uploads  -- to save the uploaded files
npm install
npm start
```
